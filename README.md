## Tech Stack
- **Next.js 15** with App Router
- **TypeScript** strict mode
- **Prisma** ORM
- **Recharts** for data visualization
- **Tailwind CSS** styling
- **React Query** data fetching
- **NextAuth.js** authentication

## Getting Started
```bash
npm install
cp .env.example .env.local
npm run dev
```
